这段代码的核心是两件事：

```cpp
int find(int x)
{
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}
```

`p[x]` 表示 `x` 的父节点。  
如果 `p[x] == x`，说明 `x` 自己就是根节点，也就是祖宗节点。

如果 `p[x] != x`，说明 `x` 不是根节点，那就继续找它父节点的祖宗：

```cpp
find(p[x])
```

找到以后，再把 `x` 的父节点直接改成祖宗节点：

```cpp
p[x] = find(p[x]);
```

这一步就是路径压缩。

举个例子，假设现在有这样一条链：

```text
1 -> 2 -> 3 -> 4 -> 5
```

意思是：

```cpp
p[1] = 2
p[2] = 3
p[3] = 4
p[4] = 5
p[5] = 5
```

其中 `5` 是祖宗节点，因为 `p[5] == 5`。

现在调用：

```cpp
find(1)
```

执行过程是：

```text
find(1)
因为 p[1] = 2，不是自己，所以 p[1] = find(2)

find(2)
因为 p[2] = 3，不是自己，所以 p[2] = find(3)

find(3)
因为 p[3] = 4，不是自己，所以 p[3] = find(4)

find(4)
因为 p[4] = 5，不是自己，所以 p[4] = find(5)

find(5)
因为 p[5] = 5，是自己，返回 5
```

然后递归开始一层层返回：

```text
find(4) 得到 find(5) = 5，所以 p[4] = 5
find(3) 得到 find(4) = 5，所以 p[3] = 5
find(2) 得到 find(3) = 5，所以 p[2] = 5
find(1) 得到 find(2) = 5，所以 p[1] = 5
```

最后数组变成：

```cpp
p[1] = 5
p[2] = 5
p[3] = 5
p[4] = 5
p[5] = 5
```

原来的树：

```text
1 -> 2 -> 3 -> 4 -> 5
```

被压缩成：

```text
1 -> 5
2 -> 5
3 -> 5
4 -> 5
5 -> 5
```

所以这句代码：

```cpp
p[x] = find(p[x]);
```

可以理解成：

> 先找到我父节点的祖宗是谁，然后让我直接认这个祖宗当父节点。

因此它既能找到 `x` 的祖宗节点，又能顺手把路径上的点都压缩到祖宗节点下面。
